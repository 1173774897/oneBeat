# 购买弹窗：三版交互方案

本轮为设计预览，没有修改应用购买流程或原始商品文案。

交互源文件：/Users/lizhe/.codex/visualizations/2026/10/29/01a187b9-ce55-7c72-a997-75f5c9b75372/purchase-dialog-variants.html。原始文案来自 docs/store/exclusive-character-copy.md；共9篇，含标点计数均不超过100字。

## 推荐与交互

推荐“权益先行”。商品名称和价格先出现，购买所得常显，人物故事或场景氛围放在独立纸白区域。原始简介中的永久解锁、使用入口、适用模式和续费说明移出故事，集中展示，避免重复。

| 方案 | 默认显示 | 查看更多 | 取舍 |
| --- | --- | --- | --- |
| 简介直展 | 3行简介 | 原位展开，原按钮变为“收起简介” | 延续现有居中弹窗；展开后购买区随内容下移 |
| 权益先行 | 权益常显，简介2行 | 简介区域原位展开 | 购买范围更清楚，适合角色、场景与月卡统一复用 |
| 详情翻页 | 简介2行 | 弹窗正文进入完整简介，可返回购买确认 | 价格、权益与操作始终保留；100字内容需要额外一次返回 |

三版使用同一套商品数据和折叠检测；只有实际超过默认行数才显示“查看更多”。商品示例可切换9个付费商品。展开、收起与翻页均仅作用于预览，确认按钮不会发起支付。

## 常显权益

- 角色：永久解锁并加入“我的”；单人、多人练习均可选用。标题下保留“独占角色”分类。
- 场景：永久解锁并加入“我的”；单人练习可选，多人场景由队长设置。
- 月卡：有效期内畅用当前与后续上架的角色、场景及PRO定制鼓机。价格显示“/月”，按月自动续费、华为账号订阅管理取消方式与取消后本期仍可用均独立显示，不放进折叠区。

这比“可在小铺和队伍中使用”更准确：“小铺”是获取和管理入口，实际使用发生在练习与队伍中。月卡不使用永久解锁表述。

预览保留原文的人物与场景描写，移出购买信息；月卡只保留原文开头的叙述，其余权益与续费信息在常显区表达。没有修改原始文档。价格为排版示例：云行者/茶壶太太12元、霓虹街口16元、月卡18元来自用户截图；其他角色暂复用12元排版示例，不代表IAP实际报价。正式实现继续读取商店返回的价格。

## 调整位置

优先通过设计控件调整，绑定值位于交互源文件的 configs：

| 参数 | 当前值 | 调整效果 |
| --- | --- | --- |
| configs.inline.lines / benefits.lines / detail.lines | 3 / 2 / 2 | 增大显示更多简介行，弹窗正文变高、后续内容下移；短文本不出现展开按钮 |
| --ob-dialog-width，对应 config.width | 388px | 增大弹窗向两侧变宽，正文换行变少；减小则更窄。受外层可用宽度限制 |
| --ob-dialog-pad，对应 config.pad | 18px | 增大内容向内收，换行变多、弹窗可能变高；减小相反 |
| .ob-stage 的 align-items | center | 控制弹窗在对比舞台垂直居中；改为flex-start会靠顶部 |
| .ob-title-price 的 flex-wrap | wrap | 窄屏允许价格换行，避免强行缩字与商品名重叠 |

纸白、珊瑚红、墨黑及青绿色均为预览根节点的--ob-*变量，保持应用的纸张与美漫控件风格。未改动任何运行时素材或场景缩放参数。
