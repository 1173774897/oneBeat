# 橘帽角色：漫画线条修订帧

- frame_01.png–frame_08.png 按原始帧序保存，共 8 张。
- 使用内置 image_gen 逐帧编辑，参照 lilroll、mismatch、wave 的墨线、排线和漫画色块；第 1 帧作为后续帧完成风格参照，动作以各自原图为准。
- 删除背景及右下角文字框，补绘被遮挡的鞋子；加入贴地的线条接触阴影。
- 输出均为 1254×1254 RGBA PNG，alpha 范围 0–255，四角透明；没有缩回 960×960。
- 未覆盖输入原图，也未修改客户端运行资源或代码。
- AI 修订并非像素级描摹，循环动画衔接及定位尚未实机验证。
- prompts.json 保存每帧完整提示词、输入参照、生成来源和验证结果。
