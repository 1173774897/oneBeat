# oneBeat 应用市场截图 · 三版连续模板

参照用户提供的横向连续截图模板，制作三版各五张的介绍截图底板。每张 1080 × 1920，手机屏幕留空，介绍文字暂不制作。

配色直接取自项目 `entry/src/main/ets/components/ComicKit.ets`：纸白 `#FFF9EE`、墨黑 `#171B1F`、珊瑚橙 `#FF7056`、丁香紫 `#C5B7EB`、青绿 `#29B5AE`、暖白 `#FFFDF8`。

| 方案 | 底色与机框 | 视觉侧重 |
| --- | --- | --- |
| A · 纸白珊瑚 | 纸白底、珊瑚框、墨色轮廓 | 接近应用当前的纸白漫画界面 |
| B · 墨黑丁香 | 墨黑底、丁香框、暖白屏幕 | 深底衬托大屏，最接近参考的明暗层级 |
| C · 丁香纸白 | 丁香底、纸白框、少量青绿阴影 | 用原有品牌色形成更轻快的系列 |

## 连续画布

每版的 01、02 来自同一张 2160 × 1920 的横向母版，在 x=1080 处切开。第一部手机从 01 下方跨进 02 左下；第二部手机从 01 右上延续到 02 上方。两部手机、底色和跨页装饰均共享坐标。

这两张不是分别排版后再对齐。PNG 先完整渲染母版，再做精确切片；SVG 也引用相同几何。把 01、02 原尺寸无间距并排，即可还原 `pair.png`。预览中的卡片间距仅用于查看，其本身不是设计内容。

01 的标题留白位于上方偏左，02 的标题留白位于下方偏右，避开两部斜向手机。03–05 为上方标题留白、下方大屏幕的独立版式，手机底部出画，便于放大实际界面。

## 文件

- 每版目录的 `01.png`…`05.png`：五张空屏底板。
- `pair.png` / `pair.svg`：前两张的连续母版。
- `strip.png`：五联预览。
- 每版同名的 `.svg`：可编辑 SVG，含每张页面与连续母版。
- `layers/`：透明屏幕覆盖层与屏幕蒙版，便于后续放入真实截图。
- `config.json`：配色、手机位置、角度、尺寸与阴影的唯一参数来源。
- `build.cjs`：生成全部导出文件及拼接检查报告。

第一、二张的真实截图需先放进连续母版的两部手机，再切片。这样跨页部分的内容和边框会一起连续；不能给相邻两张分别放两份不一致的截图。

构建使用本机已有的 sharp。每版会检查导出尺寸，并把 01、02 像素重新拼合，与母版做逐像素对比；不使用“相邻两列必须相同”这种错误判断。

## 位置与尺寸调整

首选修改 `config.json` 的 `schemes[].pairPhones`，一次调整连续母版中的手机，随后重建切片。不要分别平移已导出的 01、02 PNG，否则跨页边缘会错开。

| 方案 / 手机 | x | y | width | height | rotation |
| --- | --- | --- | --- | --- | --- |
| A / A | 300 | 740 | 810 | 1720 | -12° |
| A / B | 1130 | -360 | 810 | 1720 | -12° |
| B / A | 310 | 760 | 800 | 1700 | -14° |
| B / B | 1130 | -380 | 800 | 1700 | -14° |
| C / A | 320 | 780 | 830 | 1750 | -10° |
| C / B | 1080 | -420 | 830 | 1750 | -10° |

增大 x 向右移动、增大 y 向下移动；宽高同比增加会放大手机，单独增加一个值会改变其宽高比。rotation 围绕机身中心旋转，数值增大为顺时针；负值向零增加时会变得更直。为保留平行双机的流线感，通常同时调整两台的角度。

次要约束是固定切线 x=1080、2160 × 1920 母版裁切范围，以及 `titleSafeAreas.pair` 的标题区域：01 当前为 `(80,120,820,420)`，02 在母版中的当前区域为 `(1400,1500,650,330)`。这些区域本轮不绘制文字，只在 `layout-guide.svg` 中标示。移动手机后需确认标题留白仍可用。

后面三张由 `schemes[].singlePhones` 控制：

| 方案 | x/y/width/height | 03/04/05 的 rotation |
| --- | --- | --- |
| A | 124 / 570 / 832 / 1780；04 的 y=590 | 0° / -1.5° / 0° |
| B | 110 / 540 / 860 / 1820 | 0° / 0° / 0° |
| C | 134 / 580 / 812 / 1760 | -2° / 2° / 0° |

公共机框 `phone.radius=100`，增大更圆、减小更方；各版 `phoneOverrides.inset` 为 A=28、B=28、C=24，增加会加厚边框并缩小屏幕，减少则相反。阴影由 `schemes[].shadow` 控制：A 偏移 `(14,18)`、B 为 `(0,0)` 且透明、C 为 `(18,20)`；增大 x/y 分别使阴影向右/下移动。

画布参数 `canvas.width=1080、canvas.height=1920` 决定每张图片尺寸；宽度同时决定连续母版宽度和切线，勿只改某一张的导出宽度。

所有画面均为矢量模板，未使用位图场景层。导出背景、机框及其位置由 `build.cjs` 的 `makeSvg()` / `phoneShape()` 读取上述配置生成；具体成图路径如 `a-paper-coral/01.png`，应改配置重建，而非直接改 PNG。

```sh
node designs/app-market/2026-10-31-panorama-three/build.cjs
node designs/app-market/2026-10-31-panorama-three/compare.cjs
```

`previews/three-schemes.png` 是三版比较图，前两张在比较图中直接相连；只有总览展示用外侧圆角，实际导出文件为直角整张图片。`build-report.json` 记录三版拼接与全部 15 张导出尺寸的检查结果。
