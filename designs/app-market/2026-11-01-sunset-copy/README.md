# oneBeat · 六张应用介绍截图文案

根据用户提供的六张已放入屏幕内容的1080×1920 PNG添加原生矢量文字图层。所有屏幕内容、手机、背景及跨页关系沿用原图；本次不重新绘制图片。文件保存在项目新目录，下载文件夹中的原图未覆盖。

## 字体与颜色

使用鸿蒙黑体 **HarmonyOS Sans SC**，取自本机DevEco SDK。主标题字重900，右倾9°；副标题字重600。第一行墨黑、第二行纸白，以墨黑描边和青绿硬阴影增强美漫风格。

| 用途 | 当前参数 |
|---|---|
| 主标题 | 108px；第二张68px；字重900；右倾9°；字距0.5px |
| 副标题 | 30px；第二张25px；字重600 |
| 页码标签 | 23px，字重900，字距1.4px |
| 解锁提示 | 22px，字重600 |
| 墨黑 | `#171B1F` |
| 纸白 | `#FFF9EE` |
| 青绿 | `#29B5AE` |
| 第二行标题效果 | 墨黑描边5px；青绿硬阴影x=8px、y=9px |

字体轮廓由fontTools从真实可变字体的600/900实例生成，不依赖SVG查看器的字体替换。没有复制或打包字体文件。SVG中的文字为路径；通过layout.json可以重新修改原始文案并生成轮廓。

## 再调整位置、大小与颜色

优先改 `layout.json` 的 `pages[].x` 和 `pages[].yOffset`，能整体移动该页的文案：**x增大右移、减小左移；yOffset增大下移、减小上移**。当前第01及03—06张 `x=96`，第02张 `x=724`；六张 `yOffset=0`。

若只调某一行，再改其基线。当前位置均以该页左上角为原点，单位为成图px：

| 页面 | 页码标签eyebrowY | 第一行firstBaseline | 第二行secondBaseline | 副标题subtitleBaseline | 小标noteY |
|---|---:|---:|---:|---:|---:|
| 01 | 88 | 258 | 388 | 468 | — |
| 02 | 1394 | 1518 | 1602 | 1662 | — |
| 03 | 88 | 258 | 388 | 468 | 498 |
| 04 | 88 | 258 | 388 | 468 | — |
| 05 | 88 | 258 | 388 | 468 | — |
| 06 | 88 | 258 | 388 | 468 | 498 |

以上Y值增大时对应一行向下移动，减小时向上。它们会叠加整组yOffset；建议先用yOffset整体移动，再微调行间距。第02张的手机结束约在y1390，长椅在其左下、植物约在y1700以后，因此右下文案的可移动范围较小；第03—06张手机约从y570开始，文字小标当前结束约y534。

字大小通过 `styles.headline.fontSize=108`、`styles.compactHeadline.fontSize=68`、`styles.subtitle.fontSize=30`、`styles.compactSubtitle.fontSize=25` 控制，增大放大、减小缩小。`slantDegrees=9`增大时更向右倾。字号会改变文字占用宽高，脚本会阻止文字超出页面，但避让手机和画面主体仍需看预览确认。

`palette.ink/paper/teal`控制三种颜色；`titleEffects.outlineWidth=5`增大使纸白标题的墨黑描边更厚；`shadowX=8`和`shadowY=9`增大分别使青绿阴影向右、向下。

图片素材位于 `source/01.png`—`06.png`，由各页 `source`字段选择。build.cjs按原尺寸嵌入，不独立移动或缩放屏幕和背景。

## 重生成

在本目录运行：

```sh
python3 outline-text.py
node build.cjs
```

需要本机fontTools、Sharp及layout.json记录的DevEco SDK字体路径。修改文字、字号、字重或斜体后先生成字体轮廓；只修改位置、颜色和阴影时可以只运行build.cjs。

导出使用同一6480×1920母画布后裁成六份，已验证重组逐像素等于母图；首两张公共边缘不添加文字，保持原图跨页关系。文字区域外的原图不透明像素与透明通道均保持一致，6页26段文字无缺字、无出界；已人工检查第二张对长椅、植物的避让及其他页手机顶缘留白。

第05张屏幕内部仍含用户原图中的旧版“人声对齐”文案；应用代码已改为“时间对齐”，本次新增的营销文案也使用MIC音轨含义。正式上架前可把source/05.png替换为新版屏内截图，再重新生成。
