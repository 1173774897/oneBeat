# 个人练习大厅：可选耳机校准入口三案

交互原型源文件：`/Users/lizhe/.codex/visualizations/2026/10/29/01a187b9-ce55-7c72-a997-75f5c9b75372/optional-calibration-variants.html`。

三版原型把“耳机设置”改成与蓝牙播放补偿对应的“耳机校准”，从鼓机与出发之间移走；入口使用12px灰色字，不加红点、不做必做提示，点击后才解释用途。未连接蓝牙输出时隐藏入口。

2026-11-02：用户选择“设置卡内收纳”，已落地到应用。实际状态、源码位置和尺寸调整见 [implementation.md](implementation.md)；下方位置参数仍对应三版设计原型。

| 方案 | 位置与文案 | 取舍 |
| --- | --- | --- |
| 标题栏轻入口（推荐） | 个人练习标题右侧，耳机图标＋“耳机校准 ›” | 最轻、无需新增内容行，普通节拍与鼓机模式都能保留 |
| 设置卡内收纳 | 设置卡底部细分隔线下，“蓝牙耳机校准”，小字“声音与画面不同步时使用” | 解释直观；设置卡略长，鼓机模式也应保留同一辅助行 |
| 本机声音胶囊 | 个人队伍信息下方，“蓝牙耳机 · 校准 ›” | 与本机设备绑定，显示连接/已校准状态；上方内容略长 |

点开后的说明统一为“声音与画面对不上时，再来校准。”保留“暂时不用”与“开始校准”两种操作。后续流程为确认声音出口、跟拍测量、试听并保存。原型只展示流程入口，不进行真实声音测量。

原型可以查看未校准、已校准、重新连接、未连接，以及普通节拍和已应用鼓机两种内容状态。三版均不因启用鼓机而丢失入口。正式实现应继续沿用 `requestBluetoothCalibration()` 既有试音确认流程，避免跳过声音出口确认。

## 位置与尺寸调整

以下均修改上述原型源文件，不会自动改变应用。

| 首选参数/选择器 | 当前值 | 调整效果与限制 |
| --- | --- | --- |
| `state.entrySize` → `--ob-entry-size` | `12`px | 增大入口字更大；建议11—14，右侧空间不足时先减少文案，不挤压“个人练习”标题 |
| `state.actionGap` → `--ob-action-gap` | `14`px | 增大鼓机与出发间距；减小更紧凑，原型允许10—24，注意锁链实际非透明区域与下一按钮的间距 |
| 标题栏 `.ob-appbar` 的右内边距 | `16`px | 增大使右侧入口向左；减小向右，受屏幕边缘与触控区限制 |
| 设置行 `.ob-settings-entry` 的 `margin-top` / `padding-top` | `12`px / `11`px | 增大任一项会下移校准行并增加卡片高度；前者是分隔线前留白，后者是分隔线到文字留白 |
| 声音胶囊 `.ob-device-placement` 的上外边距 | `-11`px | 从-11增大到-5会下移胶囊6px；同时增大整个页面高度 |
| `.ob-calibration` 字色 | `#6D685E` | 维持次要文字强度；不建议改为珊瑚红或900字重 |
| `.ob-app` | `width:390px; max-width:100%` | 增大预览宽度变宽；320px外部视口仍会收缩，不影响真实应用 |

锁链使用原素材 `entry/src/main/resources/rawfile/comic/decor/pro-chain-locked.png`，原型将其编码在内嵌资源中。只为鼓机和出发靠拢做了预览尺寸调整：`.ob-chain` 当前 `width:76px; height:114px; top:-14px; right:28px`。增大宽高会放大；增大top会下移，增大right会左移。若放大锁链，需检查是否碰到出发按钮，优先维持主按钮独立可见。

实际应用后续落地入口位于 `entry/src/main/ets/pages/LeaderLobbyPage.ets`：`soloLatencyCalibrationEntry()`、`soloCalibrationEntryLabel()`，当前在 `proDrumMachineEntry()`/鼓机编排卡之后、`ComicButton`出发之前。普通队长设置仅在`rhythm !== 3`显示，选择卡内方案时必须在鼓机编排卡同步保留入口。
