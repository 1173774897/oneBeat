# 鼓机三／四／六等分实现

## 编辑与保存

- 每拍细分：`4 等分 / 3 连音 / 6 连音`。主节奏与加花分别保存各自选择。
- 切换只改变当前编辑草稿的网格，不移动鼓点、不保存段落、不重启正在试听的声音。
- 草稿以 `editorEvents` 保存真实位置、音色及力度；`editorStepVelocities` 仅为显示缓存，不参与存档或音频生成。
- 点“应用到节奏型／加花”才将当前草稿复制到相应段落；右上角关闭或返回会丢弃未应用草稿。命名保存与应用队伍继续使用主页面原流程。
- 不落格的鼓点显示为菱形。点击“就近保留 N 个其他细分鼓点”批量吸附；点击单个菱形仅吸附该音符，不删除。
- 吸附取最近的有效格子，中点等距时取前一格，小节末尾限制在最后一个格子。同音色撞到同格时合并，保留较大力度；其他鼓点的时间、力度与顺序不变。
- 普通格子仍按开关编辑；已有弱音不会因打开、切换或应用编辑器而被重设力度。

段落卡片的展开状态独立保存于页面 `expandedSections`，不再由当前编辑目标 `selectedSection` 决定。首次加载先展开 A，其他段落收起；手动点击各卡片右侧箭头可分别展开或收起。编辑 B、应用或关闭格子浮层、切换节奏型等操作不会改变 A 的展开状态。新增段落初始展开，删除段落时按原卡片携带其状态，避免字母重新编号后状态串位。收起卡片会关闭它锚定的下拉菜单，不影响试听。

整曲试听时，正在播放的段落卡片使用浅紫色背景。`playingSongSection` 由 transport 的 `mainPlayheadMs` 和本次请求提交时捕获的速度、拍号及各段重复次数计算，循环后回到对应卡片；不会按 UI 定时器次数累积时间，也不会把更新中的草稿当成正在播放的编排。加载与预播放阶段不提前高亮。停止、切换到编辑器试听或退出页面清理标记；正式播放／校准接管后按试听归属与 transport revision 拒绝其他播放的进度。高亮与段落展开状态彼此独立。

颜色在 `DrumMachinePage.ets` 的 `DRUM_SECTION_PLAYING_COLOR = '#EDE4FA'` 调整；未播放卡片仍为 `#FFFDF7`。进度读取间隔为 `DRUM_SONG_PREVIEW_PROGRESS_MS = 48 ms`，减小可更频繁刷新段落切换，增大则更省刷新开销；该值只控制显示采样，不改变音频或播放时间线。

## 打开时的默认网格

- 已保存的 `customPattern` / `customFill` 优先恢复其 `subdivision`；即使包含混合细分，也不会擅自改选或移动音符。
- 未保存网格的内置节奏，根据当前实际事件在 4／3／6 网格上的落点选择游离鼓点最少的细分；同样匹配时保留其音乐上的默认选择。爵士通常为 3，六连滚奏与 Trap“三连滚镲”为 6，其他通常为 4。
- Trap“三连滚镲”的底鼓、开镲尾部重音统一到六连音位置，打开该预设默认选中 6 连音，所有鼓点落格。该音型是十六分三连音，每个四分拍包含六个位置。
- 旧二进制行谱仍按原规则导入，以 4 等分显示；选择初始网格只影响草稿显示，不保存或量化任何鼓点。
- 真正混合细分或含微时值的节奏仍保留菱形，确保打开编辑器时不损失原始时间和力度。

## 编排补充说明

全部 12 种风格的 36 个节奏型与 36 个加花，在编辑页名称后追加说明，例如“嘻哈 · 后靠鼓点 · 刻意后靠的微时值鼓点”。后靠微时值、八等分落点及四等分／三连音混排均保留原编排和菱形显示；没有新增网格、偏移字段或隐式吸附。

说明文案由 `DrumMachineCatalog.ets` 的 `drumPatternDescription()` / `drumFillDescription()` 管理，页面 `editorPatternLabel()` 负责拼接。加花说明在需要时注明可能与主节奏形成混合细分，因为编辑页还包含加花前的主节奏。已编辑的自定义谱使用“自定义鼓点，保留原始位置和力度”，避免把原预设的特征套用到用户改过的鼓点上。

说明行在 `DrumMachinePage.ets` 的 `Text(this.editorPatternLabel())` 调整：字体 12 vp、`lineHeight(18)`、`maxLines(3)`，长文案自然换行；增大行高或最大行数会在换行时把下方工具栏和格子下移，减小则更紧凑。浮层仍受 720 vp 高度上限约束，通过已有纵向滚动容纳音轨。

文案改动前后对比 11,520 组内置编排、439,611 个鼓点，事件与原名称完全一致；事件摘要 SHA-256 为 `c035e7aa273cf2252e07ad79f61772e38e930b4235313dcd81ce86909ec65333`。页面试听、切换细分与保存规则的既有回归通过。

## 时间与兼容

新版 `DrumSection` 使用 `customPattern` / `customFill`，结构为：

```json
{
  "subdivision": 3,
  "events": [
    { "tick": 0, "sampleKey": "hat_closed", "velocity": 0.66 },
    { "tick": 320, "sampleKey": "hat_closed", "velocity": 0.46 }
  ]
}
```

`tick` 是小节内的绝对位置，每拍仍为 480 tick；网格三／四／六等分分别相距 160／120／80 tick。空 `events` 明确表示静音，不回退到预设。

旧 `customRows` / `customFillRows` 继续按原来的 `16 / beatUnit` 读取。打开旧谱时只转换显示，不取整鼓点；应用编辑后才写入新版事件格式，并移除对应旧行字段。

竖线以 `editorPlayheadBeats` 保存拍位置，随网格投影。继续使用 transport 的 `mainPlayheadMs`，停止先取最新位置，后停止音频；再试听从同一拍位置开始。数字区点击定位及横向自动跟随保留。

整曲试听时打开格子编辑浮层，整曲继续使用原 transport 播放；仅打开、编辑草稿、切换网格、数字定位或关闭浮层都不会停止或重启整曲。点击浮层“试听”才切换为当前草稿乐句，从编辑竖线位置循环播放；此后关闭浮层停止草稿试听，不自动恢复整曲。离开整个鼓机页面仍停止所有试听。点击“应用”提交鼓点时，继续沿用整曲试听的既有刷新策略。

本地鼓机试听从采样准备到播放结束持有配置归属，普通队伍 UI 更新不会覆盖音色、速度或按 idle 状态释放 renderer。`configureProgram()` 仅在本次请求已就绪时返回 true；过期采样加载返回 false，试听不能拿基础节拍序列继续起播。停止、正式 transport、校准或会话退出先撤销旧试听与未完成的采样准备；迟到的成功或失败不能影响较新的播放。鼓组资源未初始化时明确失败，避免空鼓组回退成普通点击声。

本次没有修改行进页拍相位、人物每拍帧数或音频同步补偿算法。新事件仍交由原音频渲染器按照 tick 放置；组队应用走原有共享准备与切换流程。

协议版本随十音轨扩展升至 6，沿用现有版本校验拒绝旧客户端，避免旧版缺少新音色或忽略事件谱而播放错误节奏。队伍中的手机需要更新到相同新版。

## 爵士编排

- 节奏型：经典 Swing、Jazz Shuffle、推进 Swing；默认三连网格。
- 加花：三连应答、六连滚奏、Swing 过鼓；默认网格为 3／6／3。
- Swing 使用拍内 `2/3` 的 skip 镲乐句，Shuffle 每拍使用 `0 / 320 tick` 的长短组合，六连滚奏间隔 80 tick；保留伴奏弱音和重音。
- 复合拍按三个分母拍组织乐句，保持应用原来的拍长和小节时长。十音轨扩展后，爵士主乐句使用独立叮叮镲音色。

## 位置与尺寸调整

优先在 `entry/src/main/ets/pages/DrumMachinePage.ets` 的常量区调整：

| 调整点 | 当前值 | 增大／减小的效果 |
| --- | --- | --- |
| `expandedSections` / `toggleSectionExpanded()` | 初始 `[true]`，加载后仅首项为 true | true 展开对应段落，使后续卡片下移；false 收起，使后续卡片上移。编辑目标不能用于控制此状态。 |
| `DRUM_EDITOR_CELL_WIDTH` | 22 vp | 增大格子列更宽、同屏格子更少；减小相反。按钮宽由列宽减去 `CELL_GAP = 4`，当前 18 vp，避免独立固定宽度造成重叠。 |
| `DRUM_EDITOR_SUBDIVISION_HEIGHT` | 34 vp | 增大细分按钮更高，下面的提示及网格下移；减小相反。 |
| `DRUM_EDITOR_SUBDIVISION_GAP` | 6 vp | 增大三个细分按钮间距，按钮可用宽度减少；减小相反。 |
| 新细分栏的 `Column.padding` | 左右各 16 vp | 增大内容内缩、可用宽度减少；减小相反。该栏 `space = 8` 增大会拉开各行，令网格下移。 |
| 批量就近保留按钮 `height` | 30 vp | 增大此提示按钮更高，网格下移；无其他细分鼓点时整行隐藏。 |
| `DRUM_EDITOR_OFF_GRID_SIZE` / `HIT_SIZE` | 10 / 18 vp | 前者增大菱形更大，后者增大横向点击区。横坐标由 `editorOffGridX()` 按真实 tick 投影；纵向居中在当前音色行。 |
| `DRUM_EDITOR_LABEL_WIDTH` | 56 vp | 增大左侧音色栏更宽，格子起点右移、可见格子更少；当前可完整显示叮叮镲等三字音色。 |
| `DRUM_EDITOR_MIN_ROW_HEIGHT` / `MAX_ROW_HEIGHT` | 36 / 56 vp | 控制自适应行高上下限；增大使音色行更高，后续音色下移。 |

浮层仍受 `PANEL_MAX_WIDTH = 560`、`PANEL_MAX_HEIGHT = 720` 限制。新增工具栏占用高度后，优先保留格子的点击尺寸，通过已有纵向滚动显示全部音色；六连音横向复用现有自动跟随。

## 验证范围

模型回归覆盖十二种风格的 11,520 组编排、旧行谱兼容、新事件 JSON 往返、力度和静音、爵士乐句、真实 PCM 落点及小节长度。页面回归覆盖默认网格、切换仅改草稿、单个／批量吸附、碰撞、关闭／应用、视口跟随和原有试听竞态。同步回归继续保护准备拍、共享起拍、暂停恢复、路由切换与补偿。
