# 拍手、打击乐音色更新

本页记录拍手／打击乐首次更新的 96 文件版本；当前十音轨、120 文件音色库及新版编排见 [kit-expansion.md](kit-expansion.md)。

12 种风格各替换 `clap.wav`、`perc.wav`，共 24 个文件。路径及采样长度保持不变；其余 72 个鼓音色与更新前逐字节一致。

## 合成方向

- **拍手**：单人拍掌。将掌心、指尖接触集中在 3 ms 内，通过宽频带掌心、脆响和空气声滤波，加少量快速消失的掌腔共鸣及早期反射。相比旧版间隔 18/37 ms 的重复噪声，采用更集中的起音和更短的尾音。
- **打击乐**：小型手鼓方向。用非整数频率比的鼓皮模态、手掌/指尖接触噪声及短促木腔共鸣替换固定双正弦/金属振荡器。各风格保留轻微调音、阻尼和触感区别。
- 两个模型均离线生成，没有运行时随机化。参数与噪声种子固定，重新生成可逐字节复现。
- 新模型不经过旧版重度饱和；保留接触瞬态。最终峰值仍为约 0.92，尾部仍做 128 帧淡出。短尾音使整体能量下降，试听对比没有单独补偿响度。

拍掌的共鸣滤波思路可参考 [Peltola 等人的手拍合成研究](https://vbn.aau.dk/en/publications/synthesis-of-hand-clapping-sounds/)；手部接触、气流与掌腔对声音的作用可参考 [Fu 等人的手拍声学研究](https://journals.aps.org/prresearch/abstract/10.1103/PhysRevResearch.7.013259)。本项目模型及系数为原创设计，没有使用论文音频、录音采样或测量系数。

## 生成与调整

在项目根目录运行，使用 Python 标准库即可：

```sh
python3 scripts/generate_drum_samples.py --output /tmp/onebeat-drums
```

当前生成器输出完整的 120 个 WAV 及清单。确认后可将输出复制到 `entry/src/main/resources/rawfile/drums/`，重新构建应用。`DrumSampleBank` 按进程缓存音色，更新后需要重新启动应用加载新资源。

主要调整点：

| 文件 | 参数 | 当前值与作用 |
| --- | --- | --- |
| `scripts/drum_clap.py` | `contacts`、`contact` 衰减 | 4 次接触集中在 0–2.9 ms；衰减 6.2 ms。延长会让拍掌更松散。 |
| `scripts/drum_clap.py` | `diffuse_envelope` | 24 ms，增加会延长细微空气尾音。 |
| `scripts/drum_percussion.py` | `base` | 基准 295 Hz，再按风格微调；增大让鼓皮音高上升。 |
| `scripts/drum_percussion.py` | `modes` | 每项为频率比、振幅、衰减秒数；延长高频模态会增加金属感。 |
| `scripts/drum_percussion.py` | `palm`、`fingers`、`shell` 的混合系数 | 0.33 / 0.16 / 0.20，分别控制掌击、指尖和木腔触感。 |

## 验证

- 96 个文件均保留单声道、44,100 Hz、16 位小端 PCM 和原始帧数。
- WAV 头固定 44 字节，与当前 `DrumSampleBank.extractPcm` 兼容。
- 仅 24 个目标音色哈希改变，其余 72 个完全一致。
- 24 个目标音色均从第 1 帧起音（约 0.023 ms），最终采样为 0，峰值约 0.92。
- 拍手 95% 能量位于起音后 10.2–14.3 ms，打击乐为 49.5–81.0 ms。
- 完整库重复生成后，96 个 WAV 及清单逐字节一致；签名 HAP 内的 96 个 WAV 与当前资源一致，`assembleHap` 构建通过。
- 使用现有回归夹具调用真实目录和 `renderBar`，比较 360 组新旧合奏（12 种风格、80/120/180 BPM、普通/重音、3 个预设和 2 个密集模式）。预设最终削波采样比例平均从 1.5180% 降至 1.4840%；全 8 轨十六分音符模式从 17.2905% 降至 13.4598%。3 个预设案例最多增加 4 帧，其余没有实质恶化。密集模式仍有现有混音器造成的削波，本次没有修改混音器。
- 详细帧数、哈希和电平见 [asset-audit.json](asset-audit.json)。

构建与文件检查不能替代人耳判断；最终自然度和合奏音量需通过试听确认。
