# oneBeat 正方形 App Icon 设计

三张独立 PNG，完整正方形底图，不预先切圆角；沿用应用的墨黑粗描边、奶油纸色、珊瑚橙、淡紫和青绿配色。

| 方案 | 文件 | 设计意图 |
|---|---|---|
| 01 同频脚步 | `01-same-step.png` | 两只同向鞋和节拍动势，强调一起行进、共享节奏。 |
| 02 一拍节奏 | `02-one-beat.png` | 青绿节拍器与珊瑚摆锤，突出节拍功能，轮廓简明。 |
| 03 同拍小伙伴 | `03-lamp-friend.png` | 应用台灯角色的头肩像，延续角色世界与漫画气质，品牌记忆更鲜明。 |

推荐 03；偏重功能表达可选 02，偏重结伴行进可选 01。

使用内置 image_gen 生成，完整最终提示词见 `prompts.json`。本目录保存独立设计候选；系统图标适配时按平台遮罩规范再检查角色、摆锤和鞋尖的安全范围。
