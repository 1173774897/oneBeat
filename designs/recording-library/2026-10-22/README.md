# 我的作品：双列卡片与管理

设计稿已实施到 RecordingLibraryPage.ets，适用于单人和多人作品列表。设计图使用内置 image_gen 生成，提示词保存在 prompts.json。

成稿：two-column-management.png。同一张图依次展示浏览、管理多选、删除确认三种状态；左图是滚动至作品列表后的局部，原有上方视频预览、MIC 调节和人声对齐保留。

## 浏览

- TAKES / 录制作品标题行右侧增加“管理”，空列表时隐藏。
- 作品按时间倒序双列等宽排列。卡片上部放大缩略图和播放图标，右下叠时长；下部放日期和时间。日期显示年份，例如“2026年10月22日”；点击“正在预览”动画滚动至页面顶部的视频区域，不自动播放。取消“画面 / 节奏 / MIC”。中断作品保留必要的中断标识。
- 当前预览卡片保留浅色底和“正在预览”；单击其他卡片仍切换上方预览。普通浏览不显示删除叉和选择圈。
- 延续米白、紫色、珊瑚红、黑描边、实体硬阴影的应用风格。

## 管理

- 进入时记录当前预览作品、播放断点及列表位置，暂停视频，暂收起预览、MIC 和保存区；不修改音频设置，不中断现场队伍的节奏。
- “完成”退出管理，恢复原作品及断点，保持视频暂停，清空管理选择。返回键同样先退出管理。
- 管理选择使用独立 ID 集合，不能复用当前预览的 selectedId。所有作品默认未选；点击卡片主体或左上选择圈可选中／取消。选中显示紫色对勾和浅紫底。
- 每张卡片右上出现小叉：从现有 28vp 控件缩至 14vp 视觉尺寸，保留约 44vp 透明触控热区，独立拦截点击；与左上选择圈互不重叠。
- 小叉仅打开该作品的单项删除确认，不切换预览，不改变其他作品的选择。
- 底部固定操作栏展示“全选／取消全选”“已选 N 项”“删除所选 (N)”。取消任一作品后恢复“全选”；0 项时删除按钮禁用。底部安全区和列表留出操作栏高度，不能遮挡最后一行。
- 正在保存或重新生成音频时暂不可进入管理，避免操作同一文件。

## 删除确认与结果

- 小叉使用“删除这段作品？”；批量使用“删除这 N 段作品？”。说明“将从本机作品中移除，已保存到相册的副本不受影响。”
- “取消”及返回只关闭确认框，保留选择。“删除 N 段”进入不可重复提交的处理状态。
- 成功后留在管理页，刷新数量并清空选择，提示“已删除 N 段”。全部删空时退出管理并显示现有空态。
- 部分失败时移除已完成项，保留失败项选中，提示“已删除 X 段，Y 段未完成”，可重试。
- 如原预览作品被删除，退出管理时改选时间最近的剩余作品，保持暂停。删除不会清空打卡记录或相册副本。

单人、多人作品共用这套交互，各自只管理当前列表中的作品。

## 后续布局调整

均在 entry/src/main/ets/pages/RecordingLibraryPage.ets 中调整：

| 控制项 | 当前值 | 增大后的效果（减小反向） |
| --- | --- | --- |
| LIBRARY_GRID_GAP | 12vp | 行列距离增加；总宽度固定时每列更窄 |
| LIBRARY_CARD_COVER_HEIGHT | 124vp | 缩略图和卡片整体变高 |
| LIBRARY_CARD_INFO_HEIGHT | 58vp | 卡片底部文字区域变高 |
| LIBRARY_CARD_DELETE_SIZE | 14vp | 删除叉视觉尺寸变大；不要超过触控热区 |
| LIBRARY_CARD_CONTROL_HIT_SIZE | 44vp | 选择与删除的透明触控区变大，控件中心更向卡片内部偏移 |
| LIBRARY_MANAGEMENT_BAR_HEIGHT | 64vp | 底栏变高，列表底部预留同步增加 |
| LIBRARY_SIDE_INSET | 20vp | 页面两侧留白增加，两列变窄；还需预留 4vp 实体阴影 |

缩略图来自每条作品的 clip.coverPath，缺失时使用 comic/decor/recording_share_hero.png。运行时大小优先由 LIBRARY_CARD_COVER_HEIGHT 控制，图片本身不改尺寸。卡片实体阴影为 COMIC_CARD_INK_OFFSET=4vp，小控件为 COMIC_CONTROL_INK_OFFSET=2vp。

“正在预览”返回顶部由 scrollToPreview() 的 pageScroller.scrollTo({xOffset:0,yOffset:0,animation:true}) 控制；增大 yOffset 会停在更靠下的位置。
