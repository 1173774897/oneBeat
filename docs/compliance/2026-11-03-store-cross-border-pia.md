## 一、评估工作概述

1. **起因与设计取舍**：
   - 按推荐性国家标准 GB/T 35273，"交易和消费记录"可能被认定为敏感个人信息；一旦认定，人数再少也须签订标准合同或通过认证。
   - 为避免购买记录出境，上线前（2026 年 11 月 3 日）确定的设计是：
     - 付费购买的核验、确认发货和权益判断全部在用户设备上直接与华为完成；
     - 服务器不保存购买数据：早期开发中的购买相关代码和数据表已删除，该版本从未上线；生产数据库的表结构中从未出现过购买相关的表；
     - 服务器只处理华为账号登录、兑换码和注销。
2. **范围**：仅限小铺的兑换功能。购买、恢复购买、节拍练习、附近组队（蓝牙与 Wi‑Fi P2P 直连）和录制都不经过开发者服务器。
3. **适用依据**：
   - 《个人信息保护法》第三十八至三十九条（出境条件与单独同意）、第五十五至五十六条（影响评估）；
   - 《促进和规范数据跨境流动规定》（2024 年 3 月）关于数量门槛的豁免规定；
   - 《个人信息出境标准合同办法》及其备案指南（模板结构）。
4. **局限**：本报告是开发者自评估，未经律师或认证机构审核；结论以监管部门和专业意见为准。

## 二、出境活动整体情况

### 2.1 个人信息处理者与业务

- 个人开发者，在华为应用市场发布 HarmonyOS 应用"同拍 OneBeat"（多人同步节拍器）。
- 小铺出售角色、场景（一次性永久商品）和畅游月卡（自动续费订阅），并提供兑换码活动。

### 2.2 数据流

| 环节 | 说明 |
|---|---|
| 境内端 | 用户的 HarmonyOS 设备（客户端） |
| 境外端 | 开发者租用的云服务器（中国香港），运行 `oneBeatBackend`（Go）和 PostgreSQL |
| 传输 | HTTPS（TLS），域名 `onebeatapi.liluanxin.com`（生产）／`onebeatapistaging.liluanxin.com`（测试） |
| 触发条件 | 用户使用兑换码（或同步兑换获得的权益），并且已单独同意跨境传输之后；未同意时不发送任何账号数据 |
| **不出境：购买** | 设备直接调用华为应用内支付查询购买（`iap.queryPurchases`），在设备上校验华为 JWS 签名和证书链，再在设备上确认发货（`iap.finishPurchase`）。购买数据、订单信息和购买凭据不发送到开发者服务器。设备上只保存已购商品与月卡状态摘要，不含购买凭据 |
| 不出境：其他 | 昵称、角色、节拍与鼓机设置、校准值、组队数据、录制内容、分享打卡记录 |
| 不含个人信息的出境请求 | 打开小铺时的商品目录查询（匿名，不带账号凭证）。服务端访问日志只记录请求方法、路径和耗时，不记录 IP |

### 2.3 出境的个人信息

| 种类 | 服务端实际保存形式 | 来源 |
|---|---|---|
| 华为账号标识（UnionID） | 只保存经 HMAC 处理后的不可逆值，不保存明文；OpenID 只用于核验，不入库 | 华为账号授权凭证，由服务端向华为核验 |
| 登录会话 | 无状态 JWT；服务端不保存会话表 | 服务端签发 |
| 兑换信息 | 兑换活动、兑换时间、权益有效期；**不保存兑换码明文** | 用户输入的兑换码 |
| 兑换权益记录 | 兑换权益的发放、到期、撤销及审计日志 | 服务端产生 |
| 网络地址（IP） | 只在兑换失败时**在内存中**短时计数，用于防刷；不写入数据库 | 连接本身 |

- **不涉及**：购买与订单信息、金额、订阅状态、购买凭据、昵称、头像、手机号、真实姓名、通讯录、位置、支付账户或银行卡信息。
- **规模预估**：截至评估日，应用尚未正式上架，出境人数为 0；而且只有使用兑换的用户才会出境，预计上线后一年内远低于 1 万人。

### 2.4 境外接收方

- 接收方就是开发者本人（同一个人信息处理者），并非向第三方提供。云服务商只提供计算与存储基础设施。
- 服务器位于中国香港特别行政区，适用香港《个人资料（私隐）条例》。

## 三、影响评估

### 3.1 目的、范围、方式的合法性、正当性、必要性

- **目的**：核实账号身份，发放和恢复兑换获得的权益，执行"每个账号限领一次"等活动规则。
- **合法性基础**：兑换前弹窗**单独征得同意**（《个人信息保护法》第三十九条），写明接收方、所在地、数据种类、目的和行使权利的方式；不同意不影响购买和其他功能。
- **必要性与最小化**：
  - 购买链路不经过服务器（交易记录是小铺数据中最主要的风险来源）；
  - 不获取昵称（`getNickName=0`）；账号标识不可逆处理；兑换码不保存明文；IP 不落库；
  - 商品目录查询为匿名请求。
- **透明度**：三份隐私声明（网页版、应用内版、随包副本，内容一致）的第一部分第 3 点、第三部分、第四部分、第六部分已说明上述处理。

### 3.2 规模、种类、敏感程度及对个人权益的风险

- **规模小**，且只覆盖使用兑换的用户。
- **敏感程度**：出境数据不含交易和消费记录、金融账户或其他《个人信息保护法》第二十八条所列类别，**不属于敏感个人信息**。
- **主要风险**：服务器被入侵导致兑换记录泄露。由于账号标识已不可逆处理，泄露内容难以对应到具体的人。

### 3.3 保护措施

- **传输与存储**：全程 HTTPS；账号标识 HMAC 处理；数据库端口只绑定在服务器本机（`127.0.0.1:5432`）。
- **访问控制**：会话签名校验，且每次请求校验账号状态（已注销账号的旧凭证立即失效）；日志不记录凭证和请求内容。
- **防滥用**：兑换失败按账号和 IP 限流（仅内存）。
- **注销**：用户可在应用内自助注销。注销时切断与华为账号的对应关系，撤销兑换权益；兑换记录只以去标识化形式保留。已购商品不受影响（由华为账号保管，服务器从未保存）。
- **数据库结构**：没有任何购买相关的表；权益来源由数据库约束限制为 `REDEMPTION` / `ADMIN`，购买权益写不进来。
- **权利渠道**：在线注销，以及邮箱 1173774897@qq.com（15 个工作日内处理）。

### 3.4 出境后被篡改、泄露、滥用的风险与救济渠道

- 风险主要来自服务器安全；出境数据量小、不含交易记录。
- 救济渠道：应用内注销、邮箱联系、在华为账号设置中取消对本应用的授权。

### 3.5 境外所在地的法律环境

- 香港《个人资料（私隐）条例》规定成熟；开发者是唯一接收方，没有向境外第三方再转移。

### 3.6 已接受的取舍

- 注销时不保留任何华为账号标识，所以同一华为账号注销后重新登录，可以再次兑换"每账号一次"的活动。
- "华为自动续费月卡生效期间不能领取赠送月卡"只在客户端检查，服务器不掌握订阅状态。
- 付费权益判断放在设备上，被修改过的客户端可能伪造已购状态；签名校验只能挡住伪造的购买数据。收入和订单统计看华为 AppGallery Connect 报表。

## 四、风险评估结论

- 处理目的、方式和范围合法、正当、必要；已取得单独同意并告知第三十九条要求的事项。
- 出境数据经过最小化，不含敏感个人信息；**风险总体可控**。

## 五、出境手续的适用与待办

1. **数量门槛**：非关键信息基础设施运营者自当年 1 月 1 日起累计向境外提供不满 10 万人个人信息（不含敏感个人信息）的，免予申报安全评估、订立标准合同或通过认证。本应用适用这一豁免。
2. **上线前须完成**：
   - 从生产密钥文件中删除不再使用的 IAP 和购买相关密钥；
   - 在华为 AppGallery Connect 关闭 IAP 服务端通知地址，避免华为把订单通知推送到香港服务器。
3. **持续义务**：
   - 每年 1 月统计上一年度的出境人数，接近门槛时提前办理手续；
   - 发生变化时重新评估：服务器迁移、增加数据种类（尤其是把购买数据送到服务器）、引入第三方 SDK、接收方变化。
