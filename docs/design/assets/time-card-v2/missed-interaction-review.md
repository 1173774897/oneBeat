# 整张时间卡：中断与重试交互提案

本提案接续「方案一 · 整张时间卡」的六张基础透明素材，只设计漏拍、连续敲击和采集中断后的反馈。暂不接入页面，不修改测量算法、音频调度或产品代码。

目标：机器停下后，用户能看到刚才真正打出的孔，知道这一轮没有生效，并能重新听一小节、从空白卡开始。漏掉的拍与被拒绝的敲击都不能产生孔。

## 当前代码的实际规则

依据 `entry/src/main/ets/pages/AudioCalibrationPage.ets` 当前工作区版本：

| 项目 | 已有行为 | 对交互的约束 |
| --- | --- | --- |
| 测量长度 | 120 BPM，4/4；先听 4 拍，再测 8 小节、32 次；相邻拍间隔 500 ms。常量在第 19–33 行。 | 重试仍重新听完整一小节，不从中断位置续测。 |
| 首拍 | 接受窗口为理论测量起点前 80 ms 至后 2000 ms；准备阶段及窗口前的触摸被忽略。见 `onTapTouch`、`acceptTap`，第 223–241 行。 | 宽窗口用来容纳未知蓝牙输出延迟，不能为配合动画改成 500/650 ms，也不能根据理论拍点提前显示「漏拍」。 |
| 后续敲击 | 相邻有效触摸间隔小于 350 ms 判为重复敲击；大于 650 ms 判为断拍。见第 243–252 行。 | 页面只能断言「两次敲击太近」，不能可靠区分用户连敲、抢拍或多指触摸。 |
| 等不到下一次敲击 | 首拍截止为测量起点 +2000 ms；已有有效敲击后，截止为上一有效触摸 +650 ms。见第 188–205、283–284 行。 | 中断动效的零点是判定失败的时刻，不是预期下一拍的时刻。 |
| 整体偏差 | 每个样本相对理论拍点的偏差须在 -120～2000 ms 内，否则失败。见第 255–259 行。 | 此类错误应叫「节奏偏离了」，不要伪装成确定的漏拍或连敲。 |
| 打孔与失败 | 通过所有检查后才记录样本、增加 `tapCount` 并触发打孔；拒绝事件先退出。失败保留计数与临时样本，暂停音频。见第 262–267、340–345 行。 | 孔数只能来自已经接收的样本，不能用节拍计时器生成或补齐。 |
| 保存 | `finishAndSave` 才调用 `saveCalibrationMs`。失败与重试没有持久化写入。见第 348–365 行。 | 中断卡没有结果毫秒数、试听验票灯或「保存并生效」。 |
| 既有中断页 | 当前以 `miss_burst.png` 替换机器，并统一显示「刚才断拍了」。见 `missedContent`。 | 新方案保留同一机器与纸卡，并根据实际失败原因更换文案。 |

`AppSession.scheduleLatencyTapMeasurement` 使用不带输出补偿的测量音频，并把试听小节放在同一音频时间线上。`pauseLatencyCalibration` 暂停节拍内容、保留已经唤醒的 renderer 供重试使用。中断动效不得另加提示声，也不得为了美术重试擅自销毁音频通道。

## 统一的中断动效：0–1000 ms

下面的 `T0` 指运行逻辑已经判定本轮失败的时刻。设此时已接收 `n` 次有效触摸，`0 ≤ n < 32`。先停止测量，再播放单次收束动效。

| 相对 T0 | 机器与纸卡 | 输入、状态与声音 |
| --- | --- | --- |
| 0–40 ms | 保留当前纸的位置和 `n` 个已提交孔；停止后续送料，不出现第 `n+1` 个孔。 | 立即停止接收本轮样本并发出停播请求；冻结本轮数据与失败原因，清除测量/送料/成功完成定时器。不能等动效结束后才停测。 |
| 40–180 ms | 冲头从当前位置单向退回抬起位置；扳手从当前角度回到原固定轴的休止位。无再次压下、回弹或抖动。纸保持静止。 | 这是机器收杆，不是一次打孔。没有敲击声、失败音效或震动。额外触摸不触发冲头、孔或新的失败动效。 |
| 180–320 ms | 扳手与冲头已静止；原纸卡沿导轨开始退回，镜头略向纸卡移动，已打孔与卡一起运动。 | 关闭测量触摸入口。不要持续红灯闪烁、按 500 ms 周期闪动或显示下一拍位置。 |
| 320–500 ms | 原纸卡退回至孔区可以看清的位置；在留白处一次性淡入小标签「本次未完成」。保留原来的橙色角标与所有孔，前盖与导纸夹继续保持正确遮挡。 | 标签是界面叠加文字，不由冲头「盖章」，不画新孔或判错叉号。 |
| 500–720 ms | 显示对应的失败原因，以及「保留了 n 个已打孔 · 本次未完成 32 次」。计数只在此处出现一次。 | 显示本次不计算、不保存的说明。不存在可供试听或保存的部分结果。 |
| 720–1000 ms | 原机器、原纸卡和说明完全静止；出现重试与返回按钮。 | 按钮在 1000 ms 后、且导致失败的触摸已经释放后可用；不显示倒计时，也不自动开始。 |

### 打孔动画尚未结束时失败

例如第一次触摸已被接受，第二次触摸在 20 ms 后被拒绝，第一孔的冲头动画可能尚未完成。必须把「采样已经接受」和「孔已提交」视为同一笔状态：孔可暂时被冲头遮挡，但退针后仍须显示 `n` 个孔。不能退针后只有 `n−1` 个孔，也不能为了补画第一孔再压一次扳手。被拒绝的第二次触摸从未提交孔。

### 停播请求与耳机缓冲

T0 立即停止采样并暂停音频内容，不承诺耳机能在 T0 的同一瞬间无声。已经进入蓝牙设备缓冲区的尾声可能仍会播放，这些声音不再采样，也不再推动纸或扳手。不能用「1000 ms 动效结束」代替音频停播状态判断。

## 错误类别与文案

只将应用实际检测到的情况告知用户。既有 `missReason` 字符串可作为当前设计映射依据；未来接入时宜用稳定原因类型区分，文案不应反向承担状态判断。

| 类别与触发 | 主标题 | 解释/下一次建议 | 纸卡表现 |
| --- | --- | --- | --- |
| 测量中漏拍：`n > 0`，等到截止仍无下一次触摸，或相邻间隔 >650 ms。 | 「这一拍没接上」 | 「第 n+1 次敲击没有接到。重来时只跟着耳机里的声音敲。」 | 保留前 `n` 个孔，下一格为空；不打空拍孔、不跨过空格继续收样。 |
| 连敲或抢拍：`n > 0`，相邻间隔 <350 ms。 | 「两次敲击太近了」 | 「每听到一个节拍，只轻敲一次。」 | 保留前 `n` 个孔；这次被拒绝的触摸没有孔。不要把最后一个真孔改红或删掉。 |
| 首拍未接到：`n = 0`，超过完整首拍等待窗口。 | 「第一拍还没接到」 | 「先完整听一小节，从下一个“滴”开始敲。」 | 保留空白卡，不出现孔或虚构的「第 1 次已完成」。 |
| 准备/试听时过早碰屏：`arming`，或触摸早于首拍入口。 | 不进入失败页。 | 保持原静态提示：「先听一小节，从下一个“滴”开始敲。」 | 不动机器、不打孔、不改变进度；不在每次提前碰屏后闪提示。当前逻辑也是忽略该触摸。 |
| 整体偏差越界：通过相邻间隔检查，但样本偏差越过既有总窗口。 | 「节奏偏离了」 | 「重新听一小节，跟着声音从头打卡。」 | 保留前 `n` 个孔；不显示「提前 X ms」或「晚了 X ms」来指导下一拍。 |
| 蓝牙断开/输出路由中断。 | 「耳机连接中断了」 | 「重新连接耳机后，再打一张时间卡。」 | 保留前 `n` 个孔。重试必须先满足蓝牙输出条件，不能无声启动。 |
| 音频启动失败。 | 「节拍还没开始」 | 「耳机声音没能启动，请确认连接后重试。」 | 空白卡；不把系统问题归因于用户断拍。技术错误详情与面向用户的标题分开。 |

同一错误只触发一次。采集中途应用切后台或系统中断若在后续接入中加入原因分类，应显示「本次采集被中断」，不要统一归为漏拍；当前离开页面会清理定时器并停止音频，不会保存。

### 不生效与已有校准的说明

统一基础说明：**「本次不计算、不保存。」** 根据实际持久化状态追加一行：

- 已有校准且连接未变：「已保存的校准未被覆盖。」
- 还没有校准：「重新完成 32 次敲击后，再保存新的校准。」
- 发生耳机断开或重连：「已保存的校准未被覆盖；耳机重连后请重新测量。」不承诺旧校准仍适用于新连接。

不生成补偿数值、稳定度或部分结果。失败和重试均不调用保存或清除校准；新一轮完整完成且用户保存成功后，才替换旧校准。

## 重试：换空白卡，再完整听一小节

主按钮：**「重新打卡」**。次按钮：**「返回校准大厅」**。辅助说明：**「换一张空白卡，重新听一小节，再从头开始。」** 蓝牙尚未连接时，主按钮禁用并保持「请先连接耳机」的静态说明。

1. 用户主动点击重试后，立即隔离旧轮令牌与旧触摸，只接受一次重试请求。按钮置为准备状态；不能因连续点击启动多份音频或换两张卡。
2. 旧纸卡连同孔和「未完成」标签沿既有导轨完整抽离，建议 220 ms；其后空白卡入位，建议 220 ms。这是两张纸的交接，不能把旧卡上的孔擦掉，再声称它是新卡。前盖继续遮挡经过机口的纸边。
3. 新卡就位后清空本轮临时计数、样本、上一次触摸时间与失败原因。机器保持休止位；已保存的校准不变。
4. 使用现有音频准备与完整 4 拍试听流程重新起算；准备文案固定为「正在准备耳机声音…」，进入试听后固定为「先听一小节，从下一个“滴”开始敲」。旧轮的停播、过期回调与蓝牙缓冲尾声不能被当作新轮试听。
5. 试听小节内，纸、扳手、冲头、按钮和文字都保持静止；不显示 4 个倒数点、不随拍点换色、不在理论测量起点切换「现在敲」。首次有效触摸才产生第一孔与测量中的视觉反馈。
6. 新轮从 0/32 开始；旧轮的 `n` 个样本没有任何续接或补齐入口。用户返回时同样丢弃本轮临时数据，但保留已经保存的校准。

重试音频必须继承音频层已经确认的取消/重新调度边界。页面的收卡动画只控制美术节奏，不充当音频排空确认，也不新增“准备好了”的提示音。

## 基础素材的用法与接入约束

素材目录：`entry/src/main/resources/rawfile/calibration/time-card-v2/`，六张基础图均为 1254 × 1254。

| 素材 | 中断状态职责 |
| --- | --- |
| `machine-rear.png` | 保持原机身、导轨和固定轴座，不整体抖动或倾斜。 |
| `blank-time-card.png` | 收杆后沿原导轨退回至能查看已有孔的位置；孔、角标和中断标签作为同一纸卡的子内容。只在用户重试后换卡。 |
| `punch-ram.png` | 中断时仅退回抬起位，不执行拒绝触摸的下压。 |
| `punch-guide.png` | 保持固定支撑，与冲针分离；不跟随收杆上下运动。 |
| `machine-front.png` | 持续遮住纸下缘与机口，不能为显示中断标签而隐藏前盖。 |
| `lever.png` | 绕既定轴回到休止位。沿用基础素材的轴点配准，不以 PNG 中心作为默认旋转轴。 |

在当前六层基础上，最少只需增加一个文本/标签叠加层；不需要另画一台失败机器或另一张失败卡，也不沿用替代整台机器的 `miss_burst.png`。

未来接入时应保持这些边界：

- 接受触摸、记录时间、提交孔模型先于任何动画，使用当前单调时钟和事件时间戳；不能用冲头抵达时间当作触摸时间。
- 中断先使本轮不可恢复，再清理回调。当前 `failMeasurement` 没有递增页面 `runToken`；接入时必须防止 `startMeasurement` 尚未完成的 await 在中断之后又把页面切回 `listening`。
- 350/650 ms 边界由现有采样规则决定。不能用动效时长或主线程定时器回调的先后另立一套“准时”规则；截止与触摸同刻的情况要维持一致判定。
- 停止阶段禁止收样，重试要求上一触摸已经释放。新轮使用独立令牌，旧送料、失败、完成与音频启动回调不能操作新卡。
- 不设置跟拍过程中自动超时闪灯、漏拍预警、触摸后的“正确节拍”音效或补充震动。

## 提案验收场景

这些是后续接入的人工验收条件，本次未新增或运行产品测试：

1. 已打 17 孔后漏拍：停止送料、收杆后原纸卡退回；始终只有 17 孔，空白的第 18 格不变化；最终无保存入口。
2. 有效触摸之后 20 ms 再碰屏：只保留第一次接受的孔；退针后孔数与 `tapCount` 一致，不出现第二次下压。
3. 首拍一直未收到：完整等待既有首拍窗口后才中断，整张卡保持空白。
4. 试听小节内提前碰屏：不打孔、不跳中断页、不闪动提示，仍按既有规则等待首拍。
5. 中断后继续敲：机器与孔完全静止，不触发第二次错误动效，也不误触重试。
6. 重试：先抽走旧卡，再出现新空白卡；完整重听一小节，视觉不提供拍点，新轮从 0 开始。
7. 失败、重试和返回：已经保存的校准值不被写成 0、清空或替换；耳机换连接时仍提示重测。
8. 准备时断开耳机、连续点击重试、页面离开后旧 await 返回：旧轮不能复活，不能多开节拍或更改新卡。
