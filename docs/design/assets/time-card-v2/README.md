# 整张时间卡：美术素材首版

`TimeCardCalibrationPage.ets`已接替正式耳机校准入口，原`AudioCalibrationPage.ets`源文件保留。单人大厅以小字链接提供可选校准，多人大厅保留原校准卡。本页以下记录基础素材设计阶段；运行时实施情况、入口与常量调整见`native-implementation.md`。

用户选择方案一「整张时间卡」。本目录记录素材来源、分层配准、组合预览与错过打卡时机的交互提案。基础素材阶段仅新增美术资源与独立设计预览；后续实施新增独立 `TimeCardCalibrationPage.ets`，原打卡页面保留。

## 素材清单

素材在 `entry/src/main/resources/rawfile/calibration/time-card-v2/`。六张均为 **1254 × 1254 的透明 RGBA PNG**，保留透明边，不自行裁切。

| 文件 | 内容 | 使用方式 |
| --- | --- | --- |
| `machine-rear.png` | 蓝色机身、底座、后导轨、托纸台、右侧固定轴座 | 固定后层 |
| `machine-front.png` | 珊瑚橙前盖、机口前唇、短导纸夹 | 在纸前面，遮住纸进入机身的部分 |
| `lever.png` | 青绿握柄、金属柄、左端封闭的实心黄铜轴毂 | 以银色轴心旋转，整个零件作为刚体；旧空腔图保留于archive/lever |
| `punch-ram-topdown-60.png` | 约 60° 俯视银色冲头与短针 | 与导向座同一相机方向；在四个工位移动，每次有效触摸压下一次 |
| `punch-guide-topdown-60.png` | 约 60° 俯视灰色正前支撑臂、导向套与底模 | 中央前臂与底脚一体，材质匹配机身灰沿；遮住部分冲头与下模孔，保留上套透明开口。不随冲针下压 |
| `blank-time-card.png` | 无俯视角的竖直奶油纸卡、珊瑚橙顶边、右上裁角 | 仅用这一张纸纹理；打孔代码变形成上窄下宽，送料时补偿该行宽度，结果恢复原图和规整孔格 |

所有素材由 **内置 image_gen** 生成/编辑，未通过 Python 绘画或抠图。机器母图与纸卡新生成，四个机器动画层从母图提取；扳手另做了一次安全边距修正。实际组合中补充了导向座素材，后将支撑臂完全转到镜头正前侧，并改为底座灰色金属。完整生成提示词保存在 `generation-prompts.json`、`guide-generation-prompt.txt`、`guide-foreground-prompt.txt` 和 `guide-front-gray-prompt.md`。风格参考为项目的 `calibration/punch_machine.png`、`calibration/time_card.png` 与已选中的漫画风方案图。

导向座、冲头的俯视版本先试制 45°，再按用户要求提高到约 60°。角度是漫画画面目标，并非摄影标定结果。阶段提示词见 `topdown-generation-prompts.json`。纸面后来改为只用原竖直纹理，由代码透视，不再消费预画俯视角的纸 PNG。用户替换的梯形纸图及备份完整移到 `archive/paper-perspective/`，未编辑或丢弃。

`machine-master-reference.png` 与 `selected-concept-reference.png` 是风格/结构参考，不是应当替代分层的整图。参考效果图中的孔数与文字不是运行数据；运行时由实际 32 次采样模型生成。

## 层次与配准

从后到前：**后机身 → 纸卡及孔 → 冲头 → 正前侧灰色导向座/支撑臂 → 前盖 → 扳手**。支撑臂位于冲针的镜头侧，在投影中遮住中央冲头与部分下模孔；上套顶部保持透明。灰底脚与机身横沿衔接，下段由前盖遮挡。纸与32孔/印章/文字共用一个透视容器，原生页使用共享锚点的旋转和缩放，浏览器使用等价透视矩阵。送料时同时放大当前打孔区到进纸区域宽度；结果转正，原竖直纸纹理与4×8规整孔格共同展示。

图像生成的分层比例、原点并非像素完全一致，不宜把六张 PNG 直接同原点重叠。已在 `asset-preview.html` 用实际素材检查组合，首选调整点是该文件的 `assetLayout` 常量；配准参数也记录到 `layer-layout.json`。该 JSON 是设计说明，不是产品运行配置。

| 图层/参数 | 预览值，单位为 1254 设计画布像素 | 调整方向 |
| --- | --- | --- |
| 前盖 | `scale=.88, x=50, y=110` | y 增大盖板下移、导向座露出更多，减小遮住更多；x 增大右移，scale 增大放大。应与后机身相接 |
| 纸卡 | `scale=.68, x=170, y=-7.6`；depth `.966`、perspective `.0003`、centerX628、anchorY1020 | x 增大右移，scale 增大放大；perspective 增大远端更窄、减小趋向平行；depth 增大纵向展开。结果 depth=1、perspective=0、widthScale=1 |
| 纸窗口 | 下边界 `y=785` | 增大可显示更多机内纸边，过大可能使纸露到蓝色底座外 |
| 冲头 | `scale=.4, sourceCenterX=626.5, sourceTipY=781, y=361.6, strokeY=12` | 增大 scale 放大；centerX 增大素材左移；y/行程增大针尖向下。推荐整体位置改工作面，x 随四工位变化 |
| 正前侧灰色导向座 | `scale=.166, sourceCenterX=627, sourceDieY=505, y=602.17`，z=4、冲头 z=3 | 当前 PNG 内容上移134源像素，底模锚点同步更新；scale 增大放大，centerX 增大素材左移。露出量首选改前盖 y，保持孔/针共面及 z 顺序 |
| 统一工作面 | `punchPlaneY=686` | 增大纸孔、底模和下压针尖一起下移；减小一起上移。原生页的相关 y 均由这个值计算 |
| 扳手 | `scale=.65`；素材轴心 `(690,1030)`，场景固定轴 `(1144,676)` | 场景轴 x/y 增大整体轴位向右/下；素材轴心应保持在银色轴心上 |
| 扳手动作 | 静止 `0°`，下压 `-32°` | 角度更负会向左下压得更深，接近 0 则行程减小 |
| 孔位 | 每行 4 孔、共 8 行；首孔 `(420,1020)`，横距 `150`，行距 `-82`，孔径 `26` | 横距增大孔排更宽；负行距绝对值增大行排更高；孔径增大孔更大 |
| 送料 | `sx=D(当前行y)`，`cardY=686-.68*projectedY(当前行y)` | 当前宽度补偿从1到1.1722，每一行四工位都维持相同X/Y；送料量由透视后该行坐标决定，不再是固定48.288 |
| 结果文字 | 源坐标x310、y165，宽620，行距10，三行高62/116/42 | y增大下移、减小上移；行距增大变疏、减小变紧。当前文字底y405，必须保持在孔区上缘y433以上 |

首版组合使用**冲头沿横向四工位移动，纸卡每四次进一行**的动作关系。这样纸的横向位置保持在导轨之间，扳手始终绕右侧固定轴转动。纸从下部一行开始打孔；已打孔进入机身仍保留在纸模型上，退卡与结果展示时再全部露出。前盖与窗口不能随孔数变化而消失。

将来接入页面时，整套机身应优先统一缩放、居中；再改独立层的校正值。不要通过改场景扳手轴点来补偿 PNG 留白，否则下压时轴会漂移。扳手向左下压需留出横向空间。

## 查看预览

- `asset-preview.html`：独立浏览器预览，引用上述真实 PNG。可点击“敲一下”、演示漏拍/连敲/首拍未接到，并查看换卡。不是设备测量，预览不播放节拍，不按触摸间隔判错。
- `assembly-preview.png`：基础组合与六层素材历史截图；当前以 HTML / 原生页为准。
- `missed-preview.png`：漏拍后保留 9 个孔的画面。
- `missed-mobile-preview.png`：窄屏首拍未接到的画面。
- `missed-interaction-review.md`：正式中断与重试交互提案，包含既有采样规则和后续接入边界。

独立预览先更新触摸计数，再排队播放动作；它的视觉队列不作为采样时钟。中断时清掉后续动作，保留已经接受的孔，不为被拒绝/漏掉的拍补孔。重试抽离旧卡后才清空本轮模型并装入空白卡。

## 本次检查与后续边界

基础素材阶段检查了 PNG 尺寸、RGBA 透明度、素材边距、真实图层组合和本地浏览器控制台；桌面与 390px 预览无横向溢出。旧资源均未替换。后续独立页面已编译、打包并运行测量回归验证，详见 `native-implementation.md`。

真机试用仍需按设备尺寸确认旋转包围框、触摸区域及 ArkUI 裁切行为。独立页面使用真实样本画孔；中断、重试不保存部分结果或覆盖既有校准，试听小节内不提供提前闪灯、摆杆或视觉倒数拍点。
