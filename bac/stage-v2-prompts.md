# OneBeat Sunset Stage V2 Prompts

Generated with the built-in image generation tool using the previous project assets as style references.

- `sunset_sky.png`: portrait 9:20 coral-to-peach watercolor and colored-pencil sky texture; no objects.
- `sunset_clouds.png`: transparent, horizontally tileable peach and cream cloud banks; no sky fill.
- `sunset_sun.png`: isolated transparent orange-red crayon sun disc.
- `ocean.png`: transparent, horizontally tileable turquoise ocean band with warm sunset highlights.
- `midground_dirt.png`: transparent, horizontally tileable distant orange shoreline with sparse grass tufts.
- `dirtroad1.png`: transparent portrait foreground dirt-road tile A with sparse pebbles and sketch marks.
- `dirtroad2.png`: transparent portrait foreground dirt-road tile B matching tile A boundaries with varied details.

Shared constraints: loose hand-drawn colored-pencil, crayon and watercolor paper texture; no text, characters, borders or watermark. Final normalized dimensions are 1440 x 3200, except the isolated sun at 1440 x 1440.
