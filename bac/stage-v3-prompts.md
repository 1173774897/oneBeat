# OneBeat Wide Scrolling Stage V3

Generated with the built-in image generation tool, using the original files in `bac` as style references.

- `sunset_clouds.png`: 2:1 transparent seamless sunset cloud parallax strip; distributed cloud banks without a central focal cloud.
- `ocean.png`: 2:1 transparent seamless turquoise ocean strip; continuous horizon and wave bands.
- `midground_dirt.png`: 2:1 transparent seamless distant shoreline strip; matching soil bands at both edges.
- `dirtroad1.png`: 2:1 seamless foreground road tile A; orange top berm and broad golden dirt surface.
- `dirtroad2.png`: 2:1 seamless foreground road tile B matching tile A boundaries with varied road marks.

Shared style: loose colored-pencil, crayon and watercolor paper texture, no text, characters, borders or watermark. Final production dimensions: 2048 x 1024. Each image is rendered as a two-screen-wide tile in `WalkScene`.
